# Local Android emulator

Use the `dev36` AVD for local instrumented tests. This host has a working GPU
path through the emulator's host GLES renderer. The host Vulkan path has been
observed to crash this AVD with `Failed to allocate ColorBuffer with Vulkan
backing`, so keep Vulkan disabled for reliable test runs.

## Start

Run this from the repository root in a terminal that can access the X display:

```sh
DISPLAY=:0 XAUTHORITY=/home/dev/.Xauthority QT_QPA_PLATFORM=xcb \
emulator -avd dev36 \
  -no-audio -no-boot-anim -no-snapshot -gpu host -feature -Vulkan -accel on \
  -no-metrics -crash-report-mode disabled -verbose
```

Wait for Android services before starting tests:

```sh
adb wait-for-device
adb shell getprop sys.boot_completed
adb shell service check package
```

The last command must report `Service package: found`. `adb devices` showing a
device is not sufficient while the system is still booting.

## Run instrumented tests

From a second terminal in the repository root:

```sh
./gradlew :app:connectedDebugAndroidTest --no-daemon
```

If the emulator is left running after a test session, stop it with:

```sh
adb emu kill
```
